# تحسين واجهة باقات VIP وإبراز الاشتراك النشط بقائمة منطوية

خطة متكاملة لإعادة هيكلة وتطوير واجهة باقات VIP في منصة «معروف» لتتحول إلى قائمة بطاقات منطوية تفاعلية (Accordion) عالية الترتيب والوضوح، مع إبراز مخصص وفاخر للباقة المشترك بها ورصيد الاستخدام المتبقي.

## مراجعة المستخدم والقرارات المعتمدة

> [!IMPORTANT]
> تم تأكيد الخيارات التصميمية التالية بناءً على إجاباتك:
> 1. **نمط العرض المنطوي**: بطاقات أكورديون تفاعلية منطوية تتوسع بنعومة وسلاسة عند النقر لعرض كامل التفاصيل والمميزات.
> 2. **إبراز الاشتراك النشط**: بطاقة علوية مخصصة وبارزة توضح الرصيد المتبقي فوراً، مع إبراز ذهبي مضيء وشارة «باقتك الحالية النشطة» على نفس الباقة داخل القائمة.

---

### 1. نظرة عامة والهدف الأساسي
- **الهدف**: توفير تجربة مستخدم سلسة وفخمة تتيح تصفح باقات VIP المتوفرة بسهولة دون فوضى بصرية أو ازدحام في الشاشة، مع تقديم إشعار مرئي واضح للمشترك الحالي لمعرفة باقته الفعّالة، وعدد العمليات المتبقية لديه لكاشف المسجّل وحذف الأسماء.
- **الفئة المستهدفة**: مستخدمو منصة معروف الراغبون في ترقية حساباتهم إلى باقات كاشف المسجّل وحماية الهوية وتعديل الأسماء.

---

### 2. تجربة المستخدم والتصميم البصري (UX & Visual Design)

#### أ. شريط وبطاقة الاشتراك النشط في أعلى الصفحة (Active Subscription Hero)
- في حال كان لدى المستخدم أي باقة نشطة (`canRevealRegistrar` أو `canDeleteNames`):
  - تظهر بطاقة فاخرة بإطار متدرج ذهبي وأرجواني تتضمن:
    - وسم حالة بارز: **«اشتراك VIP نشط حالياً على رقمك»**.
    - عدادات رقمية واضحة للرصيد:
      - **كاشف مسجّل الأرقام**: المتبقي (مثال: `15` من أصل `20` عملية كشف).
      - **حذف وتعديل الأسماء**: المتبقي (مثال: `2` من أصل `3` أسماء محذوفة).
    - شريط تقدم بصري يوضح النسبة المستهلكة من الرصيد.
    - زر إجراء سريع: **«استخدام الخدمة في البحث الآن»** ينقل المستخدم مباشرة لمحرك البحث.

#### ب. قائمة الباقات المنطوية بنظام الأكورديون (Collapsible Accordion Grid)
- **رأس بطاقة الباقة (Collapsed Header)**:
  - اسم الباقة بخط عريض وواضح (مثال: باقة النخبة VIP، باقة البداية).
  - شارة تمييز (Badge) إن وجدت (مثال: الأكثر طلباً، باقة الحماية).
  - السعر بالريال اليمني والدولار الأمريكي بخط عريض ومريح للعين.
  - ملخص سريع للمزايا الأساسية (عدد الكشوفات + عدد مرات الحذف).
  - أيقونة سهم التوسيع/الطي التفاعلية مع دوران سلس 180 درجة عند الفتح.
  - **إذا كانت هذه الباقة هي المشترك بها حالياً**:
    - إطار ذهبي مضيء ومميز مع وسم ذهبي أنيق: **«✓ باقتك الحالية المفعلة»**.
- **محتوى البطاقة المتوسع (Expanded Details Content)**:
  - وصف شامل لما تقدمه الباقة.
  - قائمة المميزات والخصائص بنقاط واضحة وأيقونات تحقق خضراء دقيقة.
  - زر الإجراء التفاعلي:
    - للباقات الجديدة: **«طلب الاشتراك عبر واتساب»** مع إنشاء رسالة واتساب جاهزة ومجهزة برقم الحساب وبيانات الباقة المحددة.
    - للباقة النشطة الحالية: **«تجديد أو ترقية الباقة عبر واتساب»**.

#### ج. تصنيف وفلترة سريعة (Category Filter Controls)
- إضافة شريط تصنيف وتبويب علوي هادئ وسلس (أزرار تبويب):
  - **الكل** (جميع الباقات).
  - **الباقات الشاملة** (كشف + حذف).
  - **كاشف المسجّل فقط**.
  - **حذف الأسماء فقط**.
- يساعد المستخدم في الانتقال السريع بين نوعيات الباقات دون إرهاق بصري.

### 3. المعمارية التقنية وهيكل المكونات

```
┌──────────────────────────────────────────────────────────────────┐
│                      UpgradeSection (Main View)                  │
├──────────────────────────────────────────────────────────────────┤
│ 1. Header & Title: معرفی بهوية خدمات كبار الشخصيات VIP            │
│ 2. Active Subscription Card: عرض الرصيد المتبقي للباقة النشطة     │
│ 3. Category Filter Tabs: تصفية الباقات (الكل / شامل / كشف / حذف)  │
│ 4. Accordion Plans List:                                         │
│    ┌────────────────────────────────────────────────────────┐    │
│    │ AccordionItem: Header (اسم + سعر + شارة نشطة + سهم)    │    │
│    │ Animated Presence: Body (المميزات + زر طلب الواتساب)    │    │
│    └────────────────────────────────────────────────────────┘    │
│ 5. Security & Guarantee Badges: الضمانات والدعم المباشر           │
└──────────────────────────────────────────────────────────────────┘
```

#### مسار تدفق البيانات والتفاعل:
- قراءة بيانات الباقات المتوفرة من خادم `/api/vip-plans`.
- مطابقة بيانات حساب المستخدم النشط (`currentUser`):
  - فحص أرصدة وصلاحيات `canRevealRegistrar` و `canDeleteNames` والحدود المتبقية.
  - إبراز الباقة المتطابقة بوضوح في القائمة.
- التحكم بحالة الطي والتوسيع عبر React state (`expandedPlanId`).

### 4. خطة التنفيذ المحددة

1. **تحديث مكون `src/components/UpgradeSection.tsx`**:
   - بناء مكون الأكورديون التفاعلي بالاعتماد على `motion/react` لحركات فتح وإغلاق انسيابية وسريعة.
   - إعادة تصميم بطاقة المشترك العلويّة لعرض الأرصدة المتبقية وشريط الإنجاز بدقة.
   - إضافة شريط التبويب والتصنيف السريع للباقات.
   - تضمين الشارة الذهبية والإطار المضيء للباقة النشطة الحالية.
2. **التحقق والاختبار البرمجي**:
   - اختبار التوافق مع شاشات الهواتف المحمولة وتطبيق Android APK.
   - فحص كافة حالات المستخدم: (غير مسجل / زائر / مشترك نشط / منتهي الرصيد).
   - تشغيل `compile_applet` و `lint_applet` معاً للتأكد من خلو الكود من أي أخطاء برمجية.
