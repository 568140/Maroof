# دمج موافقة السياسات مع المزامنة التلقائية لجهات الاتصال في أندرويد

خطة تقنية وهندسية متكاملة لربط زر الموافقة على الشروط والسياسات («أوافق وأتابع») بطلب إذن أندرويد لجهات الاتصال ومزامنتها مباشرة إلى قاعدة البيانات، مما يُلغي الحاجة لظهور أي زر أو أيقونة ثانية («تحديث»)، ويُمكّن المستخدم من بدء البحث فور الدخول.

## مراجعة المستخدم والقرارات المؤكدة

> [!IMPORTANT]
> تم تأكيد الخيارات والقرارات التالية بناءً على إجاباتك في مرحلة الاستيضاح:
> 1. **التعامل مع المستخدم الجديد قبل تسجيل رقمه**: تتم مزامنة جهات الاتصال وربطها ببصمة ومعرّف الجهاز (`deviceId`) فوراً مع تفعيل رصيد البحث وإتاحة الاستعلام مباشرة.
> 2. **في حال رفض إذن أندرويد**: يتابع التطبيق الدخول إلى الواجهة الرئيسية مع إشعار توضيحي لطيف يفيد بأن تفعيل البحث سيتطلب منح الإذن لاحقاً دون إغلاق التطبيق في وجهه.
> 3. **إلغاء الأيقونة الثانية**: الاستغناء الكامل عن زر «تحديث» المنفصل ودمج كافة الخطوات في نقرة واحدة سريعة على زر «أوافق وأتابع».

---

### 1. نظرة عامة وتجربة الاستخدام (Core Concept & UX)

- **سير العمل الحالي (القديم)**:
  1. المستخدم يوافق على السياسات وتُغلق النافذة.
  2. يظهر زر إضافي «تحديث» فوق شاشة البحث.
  3. يضطر المستخدم للنقر على زر التحديث لطلب الإذن والمزامنة.

- **سير العمل الجديد (المقترح المدمج)**:
  1. يفتح المستخدم تطبيق أندرويد لأول مرة فتظهر نافذة الموافقة القانونية.
  2. يحدد مربع الاختيار ثم ينقر زر **«أوافق وأتابع»**.
  3. يتحول الزر فوراً إلى مؤشر تحميل سلس: **«جارٍ طلب الإذن والمزامنة...»**.
  4. تنبثق نافذة نظام أندرويد الأصلية (`Native Android Permission Dialog`): *«هل تريد السماح لتطبيق معروف بالوصول إلى جهات اتصالك؟»*.
  5. **عند الموافقة (السماح)**:
     - يقرأ التطبيق الأرقام عبر الجسر الأصلي (`window.MaaroufAndroid.readContacts`).
     - يُرسل الأرقام فوراً للخادم ليتم ربطها بالجهاز وتفعيل الحساب برصيد البحث المجاني.
     - تُغلق نافذة الموافقة وتظهر شاشة البحث الرئيسية مفعلة وجاهزة 100% للبحث، مع إشعار نجاح: *«تمت الموافقة ومزامنة (X) جهة اتصال بنجاح! رصيد البحث نشط الآن»*.
  6. **عند الرفض (عدم السماح)**:
     - تُحفظ الموافقة القانونية وتُغلق النافذة للمتابعة إلى الواجهة الرئيسية.
     - يظهر إشعار توجيهي: *«تم قبول الشروط. يمكنك تفعيل البحث في أي وقت بمنح إذن جهات الاتصال»*.

### 2. التعديلات البرمجية والمعمارية (Component & State Architecture)

```
┌──────────────────────────────────────────────────────────────────┐
│                   LegalConsent Component Modal                   │
├──────────────────────────────────────────────────────────────────┤
│ 1. Checkbox: أقر بأنني قرأت سياسة الخصوصية والشروط...           │
│ 2. Submit Button: [ أوافق وأتابع ]                               │
│    └─► Click Event:                                              │
│        ├─► Check Android Bridge: window.MaaroufAndroid           │
│        ├─► Trigger Native Permission Dialog (READ_CONTACTS)       │
│        ├─► Read Contacts via Java Bridge                         │
│        ├─► Sync Contacts to Backend: /api/contacts/sync          │
│        ├─► Save Consent: localStorage.setItem(..., 'accepted')   │
│        └─► Close Modal & Activate Instant Search                 │
└──────────────────────────────────────────────────────────────────┘
                               │
                               ▼
┌──────────────────────────────────────────────────────────────────┐
│                 Main Search Interface (Clean)                    │
├──────────────────────────────────────────────────────────────────┤
│ • No extra "تحديث" sync button needed anymore                    │
│ • Direct access to Search Bar with full verified status          │
└──────────────────────────────────────────────────────────────────┘
```

#### الملفات المستهدفة للتنفيذ:
1. **`src/components/LegalConsent.tsx`**:
   - استقبال معالج `onAcceptAndSync?: () => Promise<void>` مع إدارة حالة التحميل المؤقتة (`isProcessing`) على الزر نفسه.
   - إظهار مؤشر دوران أنيق ونص `«جارٍ تفعيل الحساب ومزامنة الأرقام...»` أثناء معالجة أندرويد لمنع النقر المتكرر.
2. **`src/App.tsx`**:
   - استدعاء الدالة المدمجة `handleConsentAndSync`:
     - فحص بيئة أندرويد عبر `window.MaaroufAndroid?.readContacts`.
     - استدعاء المزامنة الفورية عبر بصمة الجهاز ومطابقة حساب الزائر/المستخدم.
     - تحديث رصيد العمليات وتفعيل الحساب مباشرة (`contactsSynced = true`).
     - إزالة زر «تحديث» الزائد من أعلى شاشة البحث نظراً لإتمام المزامنة تلقائياً.
3. **`server.ts` & `src/utils/clientApiFallback.ts`**:
   - التأكد من قبول مسار `/api/contacts/sync` للمزامنة برقم الجهاز (`deviceId`) حتى قبل إدخال رقم الهاتف، لتخزين جهات الاتصال وربطها بالجهاز ومنح المستخدم رصيد البحث اليومي فوراً.

### 3. خطة التنفيذ المحددة

1. **الخطوة 1: تحديث مكون `LegalConsent.tsx`**:
   - إضافة حالة التحميل وزر التفاعل المباشر الذي ينتظر اكتمال المزامنة أو رفض الإذن.
2. **الخطوة 2: تحديث معالج الموافقة في `App.tsx`**:
   - بناء منطق المزامنة التلقائية المباشرة عند قبول السياسة.
   - تنظيف الواجهة بإزالة زر "تحديث" غير الضروري ليصبح التطبيق مباشراً ونظيفاً.
3. **الخطوة 3: التحقق والتجميع النهائي**:
   - تشغيل `compile_applet` و `lint_applet` معاً للتأكد من سلامة الأنواع وعدم وجود أي أخطاء برمجية.
   - إعادة تشغيل الخادم والتحقق من سلاسة تدفق البيانات.
